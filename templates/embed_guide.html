How to Install Your Chatbot

Select your website platform below to see exact, step-by-step instructions on how to embed the Bubbl agent onto your site.

Install on Custom HTML

1

Copy your Script Tag

Go to your dashboard, click "Deploy" on your bot, and copy the provided <script> tag.

2

Open your Index File

Open your website's main HTML file (usually index.html) in your code editor.

3

Paste before the closing body tag

Scroll to the very bottom of your code and paste the script directly above the </body> tag. Save and upload your file.

<html>
  <body>
    <!-- Rest of your website -->

    <script src="https://bubbl.ooo/static/js/embed.js" data-bot-id="YOUR_ID" defer></script>
  </body>
</html>

Install on WordPress

1

Install a Code Plugin

Log in to your WP Admin dashboard. Go to Plugins > Add New. Search for and install a free plugin called "WPCode – Insert Headers and Footers".

2

Navigate to the Plugin

Activate the plugin, then look for "Code Snippets" in your left-hand WordPress menu. Click on "Header & Footer".

3

Paste in the Footer

Scroll down to the "Footer" box. Paste your Bubbl embed script here and click Save Changes in the top right. Your bot is now live!

Install on Shopify

1

Go to Theme Editor

Log in to your Shopify Admin. On the left menu, click Online Store, then Themes.

2

Edit Theme Code

Find your current live theme. Click the three dots (...) button next to "Customize", and select Edit Code.

3

Update theme.liquid

In the left sidebar under "Layout", click theme.liquid. Scroll to the very bottom of the file, paste your Bubbl embed script right above </body>, and click Save.

Install on Wix

1

Open Site Settings

Go to your Wix Dashboard. Scroll to the bottom left and click Settings.

2

Go to Custom Code

Scroll down to the "Advanced" section and click on Custom Code.

3

Add Custom Code

Click + Add Custom Code. Paste your Bubbl script into the text box. Name it "Bubbl Bot", select "Load code on each new page", choose "Body - end" for placement, and click Apply.

Install on React / Next.js

1

Inject the Script

Because React uses a virtual DOM, standard scripts behave differently. For standard React, append the script dynamically in a useEffect. For Next.js, use the built in next/script component in your root layout.

// Next.js App Router (layout.tsx) import Script from 'next/script'; export default function RootLayout({ children }) { return ( <html> <body> {children} <Script src="https://bubbl.ooo/static/js/embed.js" strategy="lazyOnload" data-bot-id="YOUR_BOT_ID" /> </body> </html> ); }
