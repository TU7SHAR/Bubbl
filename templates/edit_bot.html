How it works:
- Direct links: Found by crawling <a href> tags on each page (what you see in navigation/footer)
- Extra links: URLs, emails, and phone numbers extracted from page content (text body, not just nav)
- Find Max Links ON: Both direct + extra links are added to Managed Links after scraping
- Find Max Links OFF: Only the directly crawled page URLs are used
