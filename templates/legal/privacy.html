7. Data Security

We implement the following security measures to protect your data:

  • Encryption in transit — All data transmitted via HTTPS/TLS
  • Password security — Passwords hashed using bcrypt with salt (never stored in plaintext)
  • Access control — Organization-level data isolation; users can only access their own org's data
  • Rate limiting — Protection against brute-force attacks and API abuse
  • OTP verification — Email-based verification codes with 10-minute expiry
  • Input validation — URL safety checks, file type validation, and content sanitization
  • Secure sessions — Cookies with SameSite=None, Secure=True flags
  • Infrastructure — Database connection pooling with health checks, worker process isolation

Despite these measures, no method of electronic transmission or storage is 100% secure. We cannot guarantee absolute security and encourage you to use strong, unique passwords.
